# Chime 精选回放

## 两条独立的发布线

- `/c/<活动编号>/en|zh`：自动版，继续按既有流程取数和刷新。
- `/showcase/chime/en|zh`：人工精选版，只返回已发布的固定单文件 HTML。
- `/showcase/chime/` 默认转到英文入口。

精选入口不会运行采集、生成、自动刷新，也不会在未发布时回退显示活动 5023 的自动版。未发布返回 404；对精选入口的 POST 请求返回 405。访问 `/showcase/chime/en|zh?v=YYYYMMDD-vN` 可读取指定历史版本；不带 `v` 时读取 `current`。版本默认独立留档、不覆盖；同版本维护修复须经用户明确授权，并先备份原成品。

## 数据原则

1. 从真实来源重新核实 Chime 的活动、相关记录及关联关系，保留一份只读原始快照。
2. 在独立工作稿中人工挑选事件、合并重复信息和整理中英文表达，不直接拿自动生成的案例冒充已核对稿。
3. 每个展示事件保留来源依据。人工调整的是取舍和表达，不编造人物、时间、动作或结果；无法核实的事实不作为确定结论展示。
4. 先预览核对，再同时发布中英文版本。展示受众与内容范围未确定前，不公开精选数据。
5. 更新精选内容只能显式重新发布；每日刷新和首页的「刷新」只处理自动版。

## 存放与发布

默认根目录为项目内的 `showcase/`；可通过 `REPLAY_CURATED_ROOT` 指定其他位置。该目录不入代码仓库，同步代码时必须排除 `showcase/`。

```text
showcase/chime/
  workspace/                 原始快照、人工工作稿、核对记录；不对外提供
  releases/<版本>/
    replay.en.html           已核对的英文固定成品
    replay.zh.html           同一版本的中文固定成品
  current -> releases/<版本> 当前发布版本
```

服务只读取 `current/replay.en.html` 和 `current/replay.zh.html`，不提供目录浏览、原始 JSON 或工作稿访问。两版验收后切换 `current`；回滚时切回上一版本。不把精选文件放进 `raw/campaigns/`、`out/` 或 `state/`。

精选成品在显式重新发布前保持不变，不受后续通用代码更新或活动刷新影响。
