2026-10-31 用户定：回放的沟通记录（Slack、Gmail、HubSpot 工单、会议）不再从公司大脑（gbrain，`brain.feedmob.it.com`）读，
改为直接读上游。原因：大脑是我们自己写的聚合层，每天北京时间 10:30 才同步一次，回放读它最多晚将近一天；直接读上游更新鲜，也少绕一层。

|---|---|---|
| Slack 消息 | FeedAI（Qdrant `slack_api_messages_v3`，只读） | 和大脑里的 Slack 是同一份数据 |

| Gong 通话 | FeedAI（`gong_call_transcripts`，历史存量，不再增加） | 只拉一次 |
| Teams 会议 | 不接 | 用户说用不上 |
| 后台（Femini）、GitHub | 和以前一样直接查 | 本来就不经过大脑 |

代码在 `replay/feeds.py`。页面格式照搬大脑的导出脚本（`ken-team-brain/scripts` 下 `feedai_qdrant_sync.py`、
`fireflies_to_gbrain.py`、`extra_common.py`、`extra_feedai.py`），同一条数据渲染出来和大脑里一字不差：AI 做过的题按内容认，
换来源后已经答过的题不会重做。**改这些渲染之前想清楚**：改一个字，所有已生成活动里相关的 AI 题都会重做一遍。

## 本地副本

都在 `raw/feed/` 下，格式和以前从大脑缓存下来的一样，后面整理、筛选的代码照旧：

- `slack/<频道目录>/<日期>.json`：一个频道一天一页。频道目录和大脑页面路径一致（目录名转小写，连着的「-」并成一个、去掉首尾的「-」）。
- `emails/`、`tickets/`、`meetings/`：一个邮件线程 / 一张工单 / 一场会议一个文件；`meetings.json` 是会议清单（按 Fireflies 编号去重）。
- `slack_numbers.json`：每个 Slack 日页里出现过的数字，按链接编号、单号找相关频道用（不用每次全扫）。
- `directory.json`：邮件通讯录（认出 Slack 里哪些人是公司外的）。
- `state.json`：每类来源从几点开始拉（页面上的「数据截至」）、拉到的最新一条、多少条、出错原因。

## 什么时候刷新

- 每次生成或刷新一个活动，流水线先刷新副本（「更新沟通记录」这一步，在子进程里跑，内存随它退出释放）：
  - Slack 平时只重拉最近 3 天（几秒）；距上次全量超过 20 小时就全部重读（约 20 秒），补上改过、删掉的消息；
  - 邮件、工单每次全部重读（合计十几秒）；
  - 会议每小时最多看一次：Fireflies 直连看最近 2 天，FeedAI、Femini 里有、本地还没有的补进来。
- 刚刷新过（Slack/邮件/工单 10 分钟内，会议 1 小时内）就跳过；刚失败过 5 分钟内不重试。同一时刻只有一个刷新在跑（文件锁）。
- 一类来源失败不影响其它类，也不动已有副本；页面照旧生成，用已有副本，「数据截至」写的是副本实际的时间。
- 副本从没完整初始化过时，流水线这一步直接报错、不生成页面（不能拿不全的数据生成）。

## 凭证与开关

- `secrets/feeds.env`（权限 600，不入库）：`QDRANT_URL`、`QDRANT_API_KEY`、`FIREFLIES_API_KEY`，2026-10-31 从大脑服务器
  feedmob3 的 `/opt/ken-team-brain/env/gbrain.env` 拷来（用户同意）。Femini 用回放自己的 `secrets/femini.env`。
- 开关：`feeds.env` 里加 `REPLAY_SOURCE=direct`（环境变量优先）后重启网页服务。去掉这一行再重启，就回到经过大脑的老路（旧缓存都还在）。

## 命令（服务器 app 目录下，带上 `REPLAY_SECRETS=/home/ubuntu/ai-2734-replay-stage/secrets`）

```bash
python3 -m replay.feeds status                      # 各类副本数据截至几点、有没有出错、开关和初始化状态
python3 -m replay.feeds refresh                     # 按需刷新（够新的跳过）
python3 -m replay.feeds refresh --kinds slack --force
python3 -m replay.feeds refresh --full              # 第一次：Slack 全量 + 会议历史全部拉一遍（约 45 分钟，大头是 Fireflies 一千场会的逐字稿）
```
